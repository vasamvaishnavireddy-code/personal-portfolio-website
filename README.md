# personal-portfolio-website
Portfolio Website — A responsive and elegant personal portfolio built with HTML, CSS, and JavaScript to showcase my education, technical skills, projects, certifications, achievements, resume, and professional profiles. Designed with a clean UI, smooth navigation, interactive elements, and mobile-friendly layouts.
## Features
- Home and About sections
- Education and Technical Skills
- Projects showcase
- Certifications and Achievements
- Resume section
- Professional profile links
- Responsive design
- Interactive navigation and animations

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
